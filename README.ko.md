# Loop Snake

맵이 토러스(torus)인 네온 스타일 WPF 뱀 게임입니다. 가장자리에 닿으면 반대편으로 이어지므로
플레이 필드가 끝나지 않습니다. Visual Studio 2022(WPF, .NET Framework 4.7.2)로 제작했고,
Visual Studio MCP 자동화 서버(빌드, 디버그, 스크린샷)로 검증했습니다.

[English README](README.md)

## 게임플레이

- **무한 랩 맵** — 어느 쪽 가장자리로 나가도 반대편에서 다시 나타납니다. 뱀이 이음새를
  지나는 동안 렌더러는 양쪽에 나뉜 뱀을 동시에 그리며, 가장자리를 넘을 때마다 점수 2점을
  받습니다.
- **이음새 서지(Seam surge)** — 6번째 랩마다 30점 보너스와 함께 파티클이 터집니다.
- **콤보 체인** — 사과를 연속으로 먹으면 배수가 올라갑니다(x2 … x8). 콤보 링은 3초 동안
  줄어들므로 계속 움직여야 합니다.
- **FRENZY** — 일정 시간마다 금색 별이 나타납니다. 먹으면 세그먼트 3개 추가, 75 × 콤보
  점수, 그리고 6초 동안 사과 점수 2배와 금색 뱀 색상이 적용됩니다.
- **축소 오브(Shrink orbs)** — 파란 오브는 세그먼트를 3개 제거합니다(최소 3개 유지).
  꼬리가 길을 막을 때 유용하며 약간의 점수도 줍니다.
- **대시(Dash)** — 먹이를 먹으면 대시 게이지가 찹니다. 가득 차면 SPACE로 1.3초간 속도
  부스트를 사용합니다.
- **속도 레벨** — 사과 6개마다 뱀이 빨라집니다.
- **시간 제한 먹이** — 각 먹이에는 줄어드는 수명 링이 있습니다. 사과를 놓치면 콤보가
  끊깁니다.
- **연출** — 파티클, 떠오르는 점수 텍스트, 사망 시 화면 흔들림, 플래시 효과, 최고 점수
  저장, 합성 사운드 효과(M 키로 전환).

## 조작

| 키 | 동작 |
| --- | --- |
| 방향키 / WASD | 방향 전환 |
| SPACE | 게이지가 가득 찼을 때 대시 |
| P / ESC | 일시정지 / 재개 |
| ENTER | 게임 시작, 게임 오버 후 재시작, 일시정지 상태에서 재개 |
| M | 사운드 전환 |
| 마우스 클릭 | 창 포커스 / 게임 시작 |

창이 포커스를 잃으면 게임이 자동으로 일시정지됩니다.

## 빌드 및 실행

Visual Studio 2022에서 `snake-game.sln`을 열고 F5를 누르거나, 다음 명령을 사용합니다:

```powershell
msbuild snake-game\snake-game.csproj /p:Configuration=Debug
.\snake-game\bin\Debug\snake-game.exe
```

## 헤드리스 규칙 테스트

시뮬레이션은 엔진 전용 코드이므로 창 없이도 규칙을 검사할 수 있습니다:

```powershell
.\snake-game\bin\Debug\snake-game.exe --selftest
```

모든 검사를 통과하면 종료 코드가 0입니다. 결과 보고서는
`%TEMP%\loop-snake-selftest.txt`에 기록되며, 랩어라운드, 역방향 입력 거부, 콤보 증가와
감소, 자기 충돌, 먹이 배치와 만료, 대시 규칙, 축소 하한, 프렌지 점수, 이음새 서지,
레벨별 속도, 최고 점수 처리를 검사합니다.

## 프로젝트 구성

| 파일 | 역할 |
| --- | --- |
| `Game/GameEngine.cs` | 순수 시뮬레이션: 토러스 그리드, 뱀, 먹이, 콤보, 대시, 프렌지, 점수 |
| `Game/GameView.cs` | 커스텀 FrameworkElement: 프레임 루프, 네온 렌더링, 파티클, HUD, 메뉴, 입력 |
| `Game/SelfTest.cs` | `--selftest`에서 사용하는 헤드리스 엔진 검사 |
| `Game/Sfx.cs` | 안전한 폴백을 갖춘 소형 합성 WAV 사운드 효과 |
| `Game/HighScoreStore.cs` | `%LOCALAPPDATA%\LoopSnake\best.txt`에 최고 점수 저장 |
| `MainWindow.xaml(.cs)` | 게임 뷰를 호스팅하고 키보드 입력을 전달 |
| `App.xaml(.cs)` | 시작 처리 및 `--selftest` 처리 |
